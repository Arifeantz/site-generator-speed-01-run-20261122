Makefun Site Turbo — a faster drop-in for makefun-site 1.0.0. It builds the same static sites, byte for byte, in less CPU time: single-pass Markdown rendering, templates compiled to JavaScript functions, and fast paths for slugs, escaping and word counts. Dependency-free, pure JavaScript, no WebAssembly, no native addon.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=output node main.ts
```
